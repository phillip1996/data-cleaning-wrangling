# 🏡 Nashville Housing Data Cleanup with Python

Welcome to this data cleaning and wrangling project focused on **Nashville housing data**.  
The goal of this project was to **clean, preprocess, and prepare** the dataset for analysis using Python.

---

## 🧹 What This Project Covers

✔️ Data cleaning and standardization  
✔️ Handling missing values and duplicates  
✔️ Feature engineering for better insights  
✔️ Formatting inconsistent entries (e.g., dates, addresses)

---

## 🛠️ Tools & Technologies

- **Python**
- **Pandas**
- **Jupyter Notebook**
- **NumPy**

---

## 💡 Key Techniques Used

- `.fillna()`, `.dropna()` for missing data  
- `.str.strip()`, `.str.replace()` for text cleaning  
- `.apply()` and lambda functions for transformation  
- Conversion of data types (e.g., date fields)  
- Removal of exact and partial duplicates
